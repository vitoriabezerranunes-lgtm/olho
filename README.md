# olho

Olho robótico pra Halloween 2026: pan-tilt de 2 servos num Arduino Uno, dois HC-SR04, HM-10 BLE.
O celular é o cérebro (`docs/index.html`): detecção de rosto no navegador, voz e Claude API, mandando ângulos por Web Bluetooth.

- `olho_firmware/` — sketch do Uno + README de ligações
- `docs/` — página do cérebro (GitHub Pages)
